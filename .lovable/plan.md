# Interactive Amazon management dashboard

## Build
- Add a dedicated `/dashboard` product experience while keeping the current landing page intact.
- Create a professional app shell with compact navigation, account status, marketplace context, notifications, and mobile navigation.
- Implement the five connected working views: Connect, Analyze, Understand, Prioritize, and Act.

## User flow
- Connect: choose Amazon data sources and simulate a secure connection with visible progress and completion states.
- Analyze: run an interactive analysis across sales, keywords, PPC, competitors, pricing, reviews, and inventory.
- Understand: inspect detected changes, contributing signals, and the AI explanation behind each finding.
- Prioritize: filter and review an impact-ranked action queue with effort, confidence, and expected result.
- Act: approve or dismiss recommendations, track selected actions, and show completion feedback.
